# 会議の作法リサーチ（E1: #35）— Meet・大企業の会議運営と、オフィシャル会議モードへの反映方針

作成: 2026-11-09（丹羽） / 対象 Issue: #35（E1）、#36（E2）

## 目的

IDEA AUDITION は本質的に「プレゼン→ジャッジ→改善を繰り返す会議」。同じ仕組みを大企業の会議室でも違和感なく使えるよう、既存の会議ツールと会議運営の作法を調べ、寄せられる要素と反映方法を1枚にまとめる。バックエンド・ルール変更は対象外（見た目と文言のみ）。

## 1. Google Meet の作り（画面構成）

- 参加者はタイル状に並び、**いま話している人のタイルが枠線でハイライト**される。「誰が話しているか」が常に見える
- 下部中央のコントロールバーに集約：マイク、カメラ、字幕、リアクション、画面共有、挙手、その他、退出（赤）。操作系は1か所・アイコン中心
- 右側パネルで切り替え：会議の詳細、参加者一覧、チャット、アクティビティ。情報系は右に寄せる
- 上部に会議名（または会議コード）と現在時刻。時間の手がかりは「残り時間」ではなく**時計ベース**
- 参加前はプレビュー画面（カメラ・マイク確認）があり、「今すぐ参加」「画面共有して参加」を選ぶ
- 挙手は押した順に並び、司会が順に指名できる。発言順が仕組みで管理される
- 全体の配色は白〜ライトグレー基調に青（#1a73e8 系）のアクセント。装飾は最小限で、コントラストが高く文字が大きい

## 2. 大企業の会議の作法（運営面）

- 会議の目的を最初に明示する（報告／協議／決定のどれか）。決める会議では、**決定者（決裁者）が誰か**を置く
- アジェンダと資料は事前共有が前提。会議は「読む場」ではなく「決める場」
- 時間は終了時刻で管理する（「あと3分」ではなく「14:57まで」）。開始・終了とも厳守
- 発言は司会が**氏名で指名**する（「次は田中さんです」）。挙手→指名の順序が守られる
- 終わりに「決定事項・担当者・期限」を確認して閉じる。議事録（合意事項メモ）が残る
- 言葉遣いは敬体で統一。相づち・評価は「参考になります」「承知しました」「賛成です」のような会議の語彙
- 録音・録画は事前に断る。ミュート管理など、音まわりの作法が全場面で一貫している

## 3. Google 社内の意思決定文化（審査員が Google 社員である点への接続）

- ラリー・ペイジの会議ルール（2011年）：decision-maker がいない会議は開かない / 参加者は10人以下（『How Google Works』では8人）/ 全員が input する / 決断を会議待ちにしない
- デザインスプリント（Google Ventures、Jake Knapp『Sprint』）：Note-and-Vote（静かに書き、投票してから議論）で声の大きさの影響を消す。最終決定は多数決でなく Decider の Supervote
- Project Aristotle：有効なチームの条件は心理的安全性と発言量の平等
→ IDEA AUDITION の「審査員4人まで・全員が審査・AIが代わりにプレゼン」は、この3点と構造が一致する（ピッチ資料側の主張とも接続できる）

## 5. ライトテーマ案（tokens.css の上書き値、オフィシャル時）

| トークン | カジュアル（現行） | オフィシャル案 |
| --- | --- | --- |
| 背景 | ポップな基調色 | 白 #ffffff〜ライトグレー #f8f9fa のフラット |
| 文字 | 現行の ink | #202124（高コントラスト） |
| アクセント | 紫・金 | 紺 #0b57d0〜#1a73e8 系に一本化。金は使わない |
| 角丸・影 | 大きめ・装飾的 | 角丸 8px 程度、影は最小限 |
| マスコット | 表示 | 非表示 |
| 文字サイズ | 標準 | 基準を一段大きく（会議室のモニター前提） |

実装は tokens.css の CSS 変数を `formality` で上書きする方式が最小（#36 の方針どおり）。

## 7. 反映の進め方（#36 への接続）

1. 配色：tokens.css にオフィシャル用の上書きを追加し、`formality`（0=カジュアル、1=オフィシャル）で切り替える
2. マスコット：オフィシャル時は非表示
3. 文言：まずヘッダー（Chrome）とロビー（Intro）の主要文言から置き換え、残りは画面ごとに広げる
4. タイマー：オフィシャル時は終了時刻表示に切り替える
5. 切り替え UI：ヘッダーまたはロビーに置く。初回表示はカジュアル（デフォルト）

優先順位は 1→3。進行・投票・改善の仕組みには触らない。
