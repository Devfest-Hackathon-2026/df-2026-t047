## 背景（テストユーザーのフィードバック、2026-11-07）

- AIが考えている最中であることが、もう少し視覚的に伝わるとよい
- せっかく可愛いキャラクターがいるので、考えているときなどにちょっとした動きがあると、より魅力的になる

## いまの状態

- 下段の「AIが準備中…」は回転マークだけ
- 上段の改良中は「分析・ブラッシュアップ中」の文字とフリップの点滅だけで、キャラ自身は反応しない
- 合意台帳の更新中は何も表示されない
- キャラの動きは、待機中の上下の揺れ、ホバー時の傾き、退場予告中の揺れのみ

## やること

素材は今の静止画のまま、動きは CSS / Motion で付ける（ADR-0001）。

| 場面 | 表現 | 状態の出どころ |
|---|---|---|
| 上段の改良・相互批評を考え中 | キャラが首をかしげる、「…」の吹き出しが点滅、頭上に考え中のエフェクト | `finalist.status` が `refining` / `critiquing` |
| 質問への回答を考え中 | 回答対象のキャラが考えるポーズ、詳細の回答欄に考え中の表示 | `answers[].answer === null` |
| 下段の新しい案を準備中 | 空いた枠にキャラのシルエットと考え中の表示（回転マークをやめる） | `lowerSlots[i] === null` |
| 案ができた・改良版が公開された | 💡がポンと出て、キャラが少し跳ねる | `CANDIDATE_SPAWNED` / `FINALIST_VERSION_PUBLISHED` |
| つかまれた | 驚いた表情の演出、じたばた | ドラッグ中（表示状態） |
| 昇格した | 喜んでジャンプ、上段で着地のきらめき | `PROMOTION_CONFIRMED` |
| 見送られた・時間切れ | しょんぼり縮んでから Idea BOX へ | `CANDIDATE_ARCHIVED`（`reason`） |
| 合意台帳を更新中 | 合意メモのボタンに「📝 整理中…」 | 台帳更新ジョブの実行中（サーバーから状態を配る必要あり） |
| 待機中 | まばたき風の動き、他のキャラが選ばれたときに振り向くなどの反応 | 表示状態 |

### 実装メモ

- 合意台帳の更新中は、いまはクライアントから分からない。サーバーが `consensusUpdating: boolean` を snapshot に含めるか、Ephemeral で知らせる。
- 回答待ち・改良中の状態はすでに snapshot にあるので、表示を足すだけでよい。
- `prefers-reduced-motion` のときは動きを止め、文字の表示だけにする。
- 同時に動くキャラが多くなっても 1366×768 の低性能PCでカクつかないこと（transform と opacity だけで動かす）。
