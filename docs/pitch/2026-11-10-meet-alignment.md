# Google Meet・大企業の会議の作法にどう寄せたか（#35）

審査に Google の社員の方がいるので、「面白いけど明日から使う姿が見えない」と言われないように、オフィシャル会議モード（#36）を会議ツールの作法に寄せた。スライドの材料にする。

## 調べたこと

**Google Meet の作り**
- リンク1つで入る。入る前に名前・マイク・カメラを決める
- 参加者の映像が並び、話している人の枠が光る
- 下のバーに ミュート・カメラ・（画面共有・リアクション）・退出。ミュート中は赤
- チャット・字幕は右の列に開く
- Gemini の「メモを取る」で、会議のあとに要約・決定事項・次のアクションが届く

**大企業の会議でよくある決まりごと**
- 議題（アジェンダ）を先に決め、時間を区切って進める（タイムボックス）
- 結論は「決定事項・担当・期限」で残し、議事録を配る
- 全員に意見を言う機会を作り、賛否を記録する（声の大きい人だけで決めない）
- 決め方（多数決・決裁者）をはっきりさせる

## どこをどう寄せたか

| 会議の作法 | IDEA AUDITION（オフィシャル会議モード） |
| --- | --- |
| リンク1つで参加 | 招待リンク・共有リンクを発行。名前を入れて入る |
| 参加者の映像 | 左の列に全員の映像。話すと枠が光り、賛成した人には印 |
| 下のバー | ミュート・カメラ・発言・議事録を出力・退出。ミュート中は赤 |
| アジェンダ・タイムボックス | 議題と4つの段階（提案の審議→比較・改良→採決→最終決定）、1案ごとの持ち時間 |
| 全員の賛否を記録 | 提案ごとに「賛成 n / m」。論点ごとに賛成の割合、合意は黄色の枠に残る |
| 決め方 | 全員の賛成で採択候補へ、最後は投票（同票はホスト） |
| 議事録・決定事項 | 議事録を出力（参加者・審議した提案と結果・合意・質疑応答・発言）、決定事項の PDF（次のアクションつき） |
| チャット・字幕 | 右の列に議論の要約と発言ログ |
| キャラクター・演出 | 会議モードでは出さない（知らせも企画名で出す） |

## 「Meet の会議にそのまま持ち込める」と言える点

1. **入り方と操作が同じ**：リンクで入り、映像・ミュート・カメラ・退出が Meet と同じ場所にある
2. **進め方が会議の作法どおり**：議題と段階、持ち時間、全員の賛否、決め方がはっきりしている
3. **会議のあとに残るものが同じ**：議事録と決定事項（次のアクションつき）がその場で出せる

## まだのこと

- 画面共有・録画・Google カレンダーとの連携はない（今回は作らない）
- 社外秘の扱い：会議の記録は自前の Firestore に置く。保存期間や消し方の決まりはまだ
- 議事録の「次のアクション」に担当と期限はまだ入らない
