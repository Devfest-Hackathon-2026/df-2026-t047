# 機能の一覧（完成形と、今の状態）

- 2026-11-10 朝の時点。本番は Cloud Run の rev 00030（main の 7fb16f8）
- 資料（スライド・README・構成図・提出ドキュメント）は、この「完成形」に合わせる。**予定**のものも、完成形として図や説明に入れてよい。ただし、デモ動画と画面写真は実物だけ（偽装は審査対象外）

## 部屋と参加

| 機能 | 中身 | 状態 |
|---|---|---|
| 部屋づくり | トップの「オーディションを作る」でリンク（`/a/xxx-xxxx-xxx`）を作り、送って一緒に入る。合言葉なし | 済み |
| 審査員は4人まで | 5人目からは観覧（聞くだけ） | 済み |
| ロビーの設定 | テーマ、持ち時間（15・30・60・90秒）、合格者の人数（1〜4人）。ほかの人にはホストの値が見える | 済み |
| 最初の案の作り置き | テーマを入れている間に最初の挑戦者を作っておき、開始と同時に出す（約1.6秒 → 約0.06秒） | 済み |
| 退出 | 退出ボタンで一覧からも消える。通信が切れただけなら席を残して戻れる | 済み |

## 予選（1人ずつのオーディション）

| 機能 | 中身 | 状態 |
|---|---|---|
| 1人ずつ登場 | AI キャラが1人ずつ企画をプレゼン（#5） | 済み |
| ゴールデンブザー | 審査員それぞれが自分のブザーを押す。全員一致で合格（#5） | 済み |
| 残り時間 | 登場から右上に「あと N 秒」。残り5秒から赤、残り3秒からタイマーの音（OtoLogic） | 済み |
| 深掘りタイム | キャラにカーソルを乗せる・詳細を開く・質問すると、交代のカウントが止まる | 済み |
| 一時停止 | ブザーの左のボタンで止める・再開する。押した人が抜けたら自動で解除 | 済み |
| 交代（見送り） | この案はないと判断したら、すぐ次の人と交代 | 済み |
| 合格者待機室 | 合格したキャラが待機室の枠へ飛んでいき、枠が光る | 済み |
| 途中で決勝へ | 合格者が人数に満たなくても、ホストがいまの合格者で決勝へ進める | 済み |
| 合格後の文脈の切り替え | 合格した案についての会話は外し、決まった条件と否定した方向は残す。合格案と似た案は出さない（#6） | 済み |

## 決勝と優勝

| 機能 | 中身 | 状態 |
|---|---|---|
| 相互批評と改良 | 決勝の案どうしが批評し合い、新しい版を作る | 済み |
| 決勝の案の画像 | 決勝に上がった案ごとに、Gemini でイメージ画像を1枚作ってフリップに出す（約5秒・1枚約5円）。優勝したら同じ画像が企画書に載る。改良しても作り直さない | 済み |
| スポットライト | タップした1人に全員で注目。名前を呼ばない質問はそのキャラへ（#7） | 済み |
| 版の履歴と巻き戻し | 詳細で v1・v2… を見比べ、前の版に戻せる（新しい版として積む）（#8） | 済み |
| 考え中の見せ方 | 改良・批評・回答を考えているキャラに「…」の吹き出しと首かしげ（#10） | 済み |
| 優勝投票 | 各案の前のボタンで投票（入れ直せる）。見出しの帯に、だれが投票済みかを名前で出す（だれに入れたかは締め切るまで伏せる）。同票ならホストが選ぶ。1人だけの決勝はホストがそのまま選ぶ | 済み |
| 結果発表と表彰 | 全員が投票したら 3・2・1 のカウントダウン（THE MOMENT OF TRUTH）→ 紙吹雪・トロフィー・観客のペンライトの表彰画面 | 済み |
| 企画書 | 決勝の間に全員分を作り置きし、優勝と同時に出す（11〜13秒 → 0秒）。PDF・文章コピー・共有 | 済み |
| 読みやすい企画書 PDF | 生成した画像などを入れて読みやすくする（#38） | 予定 |
| 優勝画面で企画書をめくる | ダウンロードしなくても、その場で PDF の中身を見られる（#39） | 予定 |

## 会話と合意

| 機能 | 中身 | 状態 |
|---|---|---|
| 声の文字起こし | Gemini Live で文字にする。文字起こしは画面に出さない（#2） | 済み |
| 発言の仕分け・言い直し | 雑談・アプリの話・聞き間違いは捨て、審査の話だけを言い直して使う（#3） | 済み |
| チャット履歴 | 文字で打った発言と、仕分けで残った発言の履歴 | 済み |
| 合意メモ | 会話から論点を作り、賛成・反対した人を名前で、賛成の人数をバーで出す。画面からも賛否を付けられる | 済み |
| 審査員も案を出す | 審査員が自分の案を出せるようにする（出し方は要検討、#41） | 予定（要検討） |
| 合意の反映 | 合意が変わったら、古い前提で作った案を捨てて新しい合意で作り直す。合意が動く前に頼んで、動いたあとに届いた案も捨てる | 済み |
| 声の調子 | 声の温度感を読み、AI の文脈に入れる（#4） | 予定 |
| 音声認識の語彙 | Gemini Live に、キャラ名・企画名・企画の呼び名（「ひとり飯」など）・前の企画・テーマの根幹の語を渡す。舞台が変わったら新しい語彙で開き直す（#46） | 済み |
| 論点とテーマの照合 | テーマから離れた話題は論点（合意メモ）に入れない（#46） | 済み |
| 音声認識の精度 | モデル・設定を比べて決める（#1） | 予定 |

## 通話

| 機能 | 中身 | 状態 |
|---|---|---|
| 音声通話 | ブラウザどうしを直接つなぐ（WebRTC）。サーバーはつなぐ合図だけを CAMP で中継 | 済み |
| 中継（TURN） | 直接つながらない回線（テザリング・大学の Wi-Fi など）では Cloudflare の TURN で中継。キーはサーバーだけが持ち、ブラウザには数時間で切れる接続情報を渡す | 済み |
| マイクの共有 | 通話と文字起こしで同じマイクを使う（iPhone などで2回開くと通話の声が止まるため） | 済み |
| 顔のワイプ | 審査員の顔をカメラで映す。予選は審査員ごとの台（上にブザー、正面に顔）を画面の真ん中に並べ、決勝は下のバー、表彰は画面の下に並べる。名前・マイクのオン／オフ・声の波形・ホストの王冠つき、話すと光る。カメラは既定でオン、切った人は頭文字で枠は残る。1人あたり 480×360・15fps・160kbps まで、観覧者は受け取るだけ（#42） | 済み |
| ミュートの一貫性 | どの場面でも、ヘッダーの同じ場所で、自分のマイク・相手の声・効果音を切り替えられる（#40） | 済み（端末ごとの確認は残り） |

## 技術

| 部品 | 使い方 |
|---|---|
| Cloud Run（asia-northeast1） | 画面の配信、CAMP サーバー（WebSocket）、音声の中継、部屋づくり、通話の接続情報。1台で動かす |
| Vertex AI：Gemini 3.5 Flash | 案の生成・回答・合意の整理・発言の仕分けと言い直し |
| Vertex AI：Gemini 3.8 Flash | 改良・相互批評・企画書 |
| Vertex AI：Gemini Live | 声の文字起こし（予定：声の調子） |
| Vertex AI：Gemini Embedding | 似た案を出さない・好みとの近さ |
| Firestore | 確定したイベントと最新の状態（再起動しても続きから） |
| Secret Manager | TURN のキー |
| Cloud Build・Artifact Registry | コンテナを作って保管し、Cloud Run へ出す |
| Google STUN | 通話の経路探し |
| Cloudflare TURN | 直接つながらないときの通話の中継（Google Cloud の外） |
| CAMP（自作のプロトコル、`packages/camp`） | 人の操作と AI の結果を、部屋ごとに1つの順番で確定する。commandId で二重実行を防ぎ、epoch で古い AI の結果を捨てる。npm に `@camp-protocol/kit@0.1.0` として公開（公開リポジトリ github.com/camp-protocol/camp、#23）し、アプリも npm の版を使う |
