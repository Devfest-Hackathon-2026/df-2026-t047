# デモ動画の台本（4人）— 大学の学食をもっと楽しくする企画

- 撮る人：牧（ホスト）・丹羽・宮原・森田。本番 URL で、4人とも声とカメラをオン
- 長さの目安：撮るのは 6〜8 分、編集して 2 分半〜3 分にする
- **見せたいこと**：私たちの会話が、その場で合意メモになり、次に出てくる案と決勝の改良に反映されていく（AI が提案し、人間が理由を持って決める）

## なぜ会話を決めておくか

アプリは、声の発言を AI で仕分けて、審査の話だけを使います。そのため、次の3つを守ると、出力を狙った方向に寄せられます。

1. **論点は短く、言い切る**：「〜がいい」「〜はなし」。雑談や「えーと」は捨てられる
2. **賛成・反対は、どの論点かを言ってから**：「一人でも気まずくない、に賛成」のように言うと、合意メモに名前つきで残る。4人のうち3人が賛成すると「合意」になる。
   - 「賛成。あと〜」と新しい論点と混ぜると、賛成が記録されない
   - 「日替わりなら飽きない」のように言い換えると、別の論点として立ってしまう
   - （2026-11-10 に手元で通しを2回試して分かった。直した言い方で、3つとも4人の合意になった）
3. **キャラには名前で話しかける**：「ルナ、〜して」と言えば、そのキャラへの頼み（決勝では改良）になる

合意が新しくできると、それまでの作り置きの案は捨てられ、新しい合意をもとにした案が出てきます。つまり、**会話の直後に出てくる案が変わる**のが見せ場です。

## 合意させる3つの論点（全員で覚えておく）

| # | 論点（この言葉で言う） | 誰が言い出す | 反対する人 |
|---|---|---|---|
| A | 一人で来た学生も気まずくない仕組みがいい | 森田 | なし（全員賛成） |
| B | 今の学食のまま、お金をかけずにできるものにしたい | 宮原 | なし（全員賛成） |
| C | 毎日ちょっとした楽しみが増える、ゲームっぽさがほしい | 丹羽 | 牧が「毎日だと飽きるかも」と一度反対し、あとで賛成に変える |

論点 C は、合意メモで賛成のバーが動く様子（2/4 → 3/4 → 4/4）を見せるためのものです。

## 撮影の前に

- ロビー：テーマ「大学の学食をもっと楽しくする企画」、持ち時間 **60秒**、合格者 **3人**
- **合格させる間は 30秒以上あける**（決勝の案の画像は、Gemini で1分に2枚ほどしか作れない。続けて合格させると画像が遅れる）
- 撮影の直前に、ほかの部屋で決勝まで進めない（画像の枠を使ってしまう）
- 画面の録画はホスト（牧）の画面。合意メモのパネルは開いておく
- キャラの名前は毎回変わるので、台本の **［キャラ］** はその場の名前に置き換える

## シーン 1：はじまり（0:00〜0:20）

| 誰 | 言うこと・すること |
|---|---|
| 牧 | 部屋を作り、リンクを送る。3人が入ってワイプに顔が並ぶ |
| 牧 | 「今日は、大学の学食をもっと楽しくする企画を決めます」→「オーディションをはじめる」 |

**映すもの**：テーマを入れて押した瞬間に、最初のキャラがもう出てくる（作り置き）

## シーン 2：予選の1人目 — 論点 A・B を出す（0:20〜1:30）

1人目のキャラがプレゼンする。中身にかかわらず、ここで論点を出す。

| 誰 | 言うこと |
|---|---|
| 森田 | 「面白いけど、学食って一人で来る人も多いよね。**一人で来た学生も気まずくない仕組みがいい**」 |
| 丹羽 | 「一人でも気まずくない、に賛成」 |
| 宮原 | 「一人でも気まずくない、に賛成」 |
| 牧 | 「一人でも気まずくない、に賛成」 |
| 宮原 | （3秒ほどあけて）「もう一つ。**今の学食のまま、お金をかけずにできるもの**にしたい」 |
| 森田 | 「お金をかけずに、に賛成」 |
| 丹羽 | 「お金をかけずに、に賛成」 |
| 牧 | 「お金をかけずに、に賛成」 |

- 名前を呼ばずに話すと、舞台のキャラが質問と受け取って答えることがある（試したときは「工事は不要です！」と答えた）。そのまま流してよい
- 1人目の案が A・B に合わなければ「交代」（見送り）。合えば4人でブザー
- **映すもの**：合意メモに論点 A・B が名前つきで現れ、賛成のバーが 4/4 になる

## シーン 3：予選の2人目以降 — 合意が案に効く（1:30〜3:30）

合意ができたあとに出てくるキャラは、A・B を前提にした案を出す（作り置きの古い案は捨てられ、新しい合意で作り直される）。
合意の直後の1人だけは、前の合意で作った案が残っていることがある（舞台を空けないため）。合わなければすぐ「交代」する。

| 誰 | 言うこと |
|---|---|
| 丹羽 | 「次は、**毎日ちょっとした楽しみが増える、ゲームっぽさがほしい**」 |
| 牧 | 「ゲームっぽさは、毎日だと飽きるかも。反対」 |
| 宮原 | 「ゲームっぽさに賛成。日替わりにすれば飽きない」 |
| 森田 | 「ゲームっぽさに賛成」 |
| 牧 | 「ゲームっぽさ、日替わりならありだね。賛成に変える」 |

- A・B・C に合う案が出たら、4人でブザー → 合格（合格は 30秒以上あけて3人まで）
- 合わない案は「交代」。迷ったら声で「うーん、［キャラ］の案はちょっと違うかな」（キャラが受け止めて別の案を出す）
- 気になる案は、キャラに声で質問する：「［キャラ］、一人で来た人はどうやって参加するの？」（質問中は時間が止まる）
- **映すもの**：C のバーが 2/4 → 3/4 → 4/4 と動くところ。そのあと出てくる案に「日替わり」「ゲーム」が入っているところ

## シーン 4：決勝 — 頼んだことが新しい版になる（3:30〜5:30）

3人が合格すると決勝。画像が各案のフリップに出る。

| 誰 | 言うこと・すること |
|---|---|
| 牧 | いちばん気になる案のキャラをタップしてスポットライト |
| 宮原 | 「［キャラ］、**お金をかけずに**できるように、今ある食券機とトレーだけでやる形にして」 |
| （画面） | キャラが考え中（…）→ 版が v2 に上がり、フリップの「この版で変えたこと」と 💬（反映した意見）が変わる |
| 森田 | 「［キャラ］、**一人で来た学生**が一番得をするようにできる？」 |
| 丹羽 | 「［ほかのキャラ］の案、［キャラ］の案と組み合わせられそう」（相互批評の吹き出しが出る） |

- **映すもの**：頼んだ直後に版が上がり、合意メモの論点がフリップの 💬 に出るところ。版の履歴（詳細）で前の版と見比べる
- 試したときは、頼んでから約3秒で新しい版になり、💬 に A・B・C の3つが出た（「スマホを使わず今ある食券機とトレーで完結」）

## シーン 5：投票 → 表彰 → 企画書（5:30〜7:00）

| 誰 | 言うこと・すること |
|---|---|
| 牧 | 「優勝を決める」→ 各案の前の「あなたの1票」 |
| 4人 | 3人が同じ案、1人が別の案に入れる（見出しの帯に、投票済みの人の名前が並ぶ） |
| （画面） | 全員が入れると 3・2・1 のカウントダウン → 表彰 |
| 牧 | 企画書を開いて、画像と「この企画に決まるまで」（合意した A・B・C と改良の経緯）を見せる |

- **映すもの**：企画書に、自分たちの合意（A・B・C）と頼んだ改良がそのまま書かれているところ。待ち時間なしで出る

## 撮影のときのコツ

- 1人ずつ、はっきり短く話す。同時に話すと、文字起こしが混ざる
- 論点は台本の言葉どおりに言う（言い換えると、合意メモの論点が分かれてしまう）
- 雑談・機材の話（「声聞こえる？」など）は、撮り直す部分でだけする（アプリは捨てるが、動画には残る）
- 合意メモの更新は、話してから数秒かかる。次の人は 2〜3 秒あけて話す
- 失敗したら：ホストの「最初からやり直す」でやり直せる。きれいに撮り直すなら、新しく部屋を作る

## 編集で残す場面（2分半〜3分）

1. テーマを入れた瞬間にキャラが出る（作り置き）
2. 論点 A・B が名前つきで合意メモに入る
3. 論点 C のバーが反対から賛成に動く
4. 合意のあとの案に、合意の中身が入っている
5. 決勝で頼んだ直後に版が上がり、💬 に合意が出る
6. 投票済みの名前 → カウントダウン → 表彰
7. 企画書（画像と「この企画に決まるまで」）
