# 新しい審査フローの画面（1人ずつ登場）— 言葉での仕様と ChatGPT 用プロンプト

- 作成：2026-11-09（牧の指示をもとに）
- 対応する Issue：#5（1人ずつ登場して全員のボタンで決勝へ）
- 方針：**今の画面をほぼそのまま使う**。変えるのは「下段に5人並ぶ → 1人ずつ」と、それに必要な最小限の部品（ゴールデンブザー・合格者待機室・これまでの挑戦者）だけ
- 元にする画面：`slide-assets/stage.jpg`（今の本物の画面）

## 1. 変えないもの（今の画面のまま）

- **ヘッダー**：アイコン、IDEA AUDITION、部屋の ID、参加人数、AI：Gemini、通話中、コピー、招待
- **テーマの帯**：「● LIVE　本日のテーマ　大学の学食をもっと楽しくする企画」
- **背景**：紫のスポットライトの舞台、光る円形のステージ（床の楕円）
- **キャラ**：今のマスコットの見た目と大きさの感覚。案は「フリップ」（企画名・アイコン・2行の説明が入った、枠が光るカード）で見せる
- **下の審査員のバー**：A ゆうと（あなた）・B たつき・C ゆうや・D みなみの札、マイク、発言の入力欄、「好み」「合意メモ」「アイデアBOX」のボタン、やり直しのボタン
- **右上の「優勝を決める ↗」**（3人そろうまでは押せない見た目）
- 色・フォント・角丸・光り方など、デザインの全部

## 2. 変えるもの

### A. 下段：5人並び → 1人だけ（いちばん大きい変更）

- 「新規アイデア発表ステージ」の5人のキャラと5枚のフリップをやめ、**ステージの真ん中に1人だけ**立たせる
- そのキャラのフリップは、今と同じデザインのまま少し大きくして、キャラのすぐ右に置く
- 1人だけで寂しくならないよう、スポットライトをその1人に集める。ステージ（床の光る楕円）は今と同じ位置と大きさのまま

### B. ゴールデンブザー（新しい部品）

- 1人のキャラの足元（ステージの手前）に、横長の金色のボタン「★ ゴールデンブザー」を1つ置く
- その右に「賛成 2 / 4」と、審査員4人ぶんの小さな丸を並べる。押した人の丸は、その人の色（A ピンク・B 青・C 黄・D 緑）で光る
- 押した人は、下の審査員のバーの札にも小さな金色の印が付く
- **4人全員が押したら（満場一致）**、そのキャラは合格して合格者待機室へ移り、次のキャラが1人登場する
- 押されないまま時間（10〜15秒）が過ぎたら、次のキャラと交代する。残り時間は、ブザーの上の細い線か、ステージの楕円の光が減っていくことで見せる（大きな数字は出さない）

### C. 合格者待機室（今の「最終オーディション」の場所を使う）

- 今の上段の「最終オーディション」の3つの空席は、**予選のあいだは左上の小さな「合格者待機室」**にまとめる
- 中身：見出し「👑 合格者待機室　1 / 3」と、横に3つの小さな席。合格したキャラは顔の丸アイコンと企画名で席に座る。空いた席は点線の丸
- 3人そろったら、今と同じ「最終オーディション」（上段に3人が並ぶ今の画面）に切り替わる。決勝の画面は今のまま

### D. これまでの挑戦者（下に参考程度）

- 審査員のバーのすぐ上に、細い横一列「これまでの挑戦者」を置く
- 出番が終わったキャラが、小さな顔アイコンと企画名で左から並ぶ。合格した人には「合格」、見送られた人には「見送り」の小さな印
- 目立たせない（少し暗く・小さく）。押すと、今と同じ詳細の画面が開く

## 3. やらないこと（変えすぎない）

- 下段に複数のキャラやフリップを並べない（**新しく出るアイデアは常に1人だけ**）
- 審査員の大きな丸いボタンを4つ並べるなど、新しい大きな部品は足さない
- 好みのグラフ、コメント欄、タイマーの大きな数字など、新しいパネルを画面に常に出さない（今と同じくボタンで開く）
- ヘッダーや下のバーの並び・ボタンを変えない
- 配色やキャラの絵柄を変えない

## ChatGPT に渡すプロンプト

添付するもの：
1. **今の本物の画面**：`docs/pitch/slide-assets/stage.jpg`。必ず添付する。これを編集してもらう
2. 前に ChatGPT が作った画像：任意。合格者待機室とゴールデンブザーの見た目の参考にだけ使う

```
添付の1枚目は、私たちのアプリの今の本物の画面です。この画面を「編集」して、新しい審査の流れの画面を1枚作ってください。新しく描き起こすのではなく、1枚目をできるだけそのまま残して、指定した場所だけを変えてください。

【そのまま残すもの（1ピクセルも変えないつもりで）】
- 上のヘッダー全部（アイコン、IDEA AUDITION、部屋のID、人数、AI：Gemini、通話中、コピー、招待）
- 「LIVE 本日のテーマ 大学の学食をもっと楽しくする企画」の帯
- 一番下の審査員のバー（A〜D の4人の札、マイク、発言の入力欄、好み・合意メモ・アイデアBOX のボタン）
- 右上の「優勝を決める」ボタン
- 紫のスポットライトの舞台の背景、光る円形のステージの床
- キャラクターの絵柄、フリップ（企画名とアイコンと説明が入った光るカード）のデザイン、色、フォント

【変えるところは4つだけ】
1. 下の段の「新規アイデア発表ステージ」に今5人並んでいるキャラと5枚のフリップを消して、ステージの真ん中に1人だけにする。キャラは魔法使いの帽子の青い猫（LUNA）。そのフリップ「余り食材ガチャ」を、今と同じデザインのまま少し大きくして、キャラのすぐ右に置く。スポットライトをその1人に集める。
2. そのキャラの足元に、横長の金色のボタン「★ ゴールデンブザー」を1つ置く。右に「賛成 2 / 4」と小さな丸を4つ並べ、そのうち2つをピンクと青で光らせる。
3. 上の段にある「最終オーディション」の3つの空席を、左上の小さな枠「👑 合格者待機室 1 / 3」にまとめる。席は横に3つの小さな丸。1つ目にはライオン（LEO）の顔と企画名「スローフード食堂」、残り2つは点線の空席。上の段の残りの場所は、舞台の暗い背景とスポットライトのままにする。
4. 一番下の審査員のバーのすぐ上に、細い横一列「これまでの挑戦者」を置く。小さな顔アイコンと企画名を3つ、少し暗めに並べる：LEO「スローフード食堂」に金色の小さな「合格」、MIST「スマホ一画面食堂」と MOMO「常連の隠し味」に灰色の小さな「見送り」。

【やってはいけないこと】
- 下の段に、2人以上のキャラや2枚以上のフリップを置かない（新しいアイデアは必ず1人だけ）
- 新しいパネル（グラフ、コメント欄、大きなタイマー、大きな丸いボタンを4つ並べる、など）を足さない
- ヘッダー・テーマの帯・下のバーの文字や並びを変えない
- 色、キャラの絵柄、全体のレイアウトを変えない
- 指定していない文字を足さない

画面の比率は1枚目と同じ（16:9）にしてください。
```

うまくいかないときの直し方（追加で送る文）：
- 5人並びに戻ってしまう →「下の段のキャラは1人だけです。ほかの4人とそのフリップは消してください」
- 全体を描き直してしまう →「1枚目の画面を編集してください。ヘッダーと下のバーは1枚目のまま残してください」
- 合格者待機室が大きすぎる →「合格者待機室は左上の小さな枠です。上の段の3分の1以下の大きさにしてください」

## 改訂（2026-11-09 牧）：予選のあいだは上の段をなくす

- **予選の画面は、ステージ1つだけ**にする。上段の「最終オーディション」（見出し・空の楕円のステージ・スポットライト3本）は、予選のあいだは出さない
- 3人が合格したら、**画面ごと「最終オーディション」に切り替わる**（決勝の画面は今のまま）
- 空いた分、1人の挑戦者のステージを画面の縦いっぱいに使う（キャラとフリップを大きく、真ん中に）
- 合格者待機室は、左上に小さく重ねて置く（「👑 合格者待機室 1 / 3」）
- 「優勝を決める」ボタンは予選のあいだは出さない。「5 AI」のバッジも消す（1人ずつなので）
- 上の「2. 変えるもの」の C（最終オーディションの場所を使う）は、これに置き換える

### ChatGPT で編集中の画像に送る文

```
この画像をもとに、次の点だけ直してください。ほかは今のまま残してください。

1. 上の段をまるごと消す：「最終オーディション FINAL STAGE 0/3」の見出し、空の楕円のステージ、スポットライト3本、右上の「優勝を決める」ボタン。予選のあいだは上の段は使いません（3人そろったら画面ごと最終オーディションに切り替わります）。
2. 「新規アイデア発表ステージ」を画面の縦いっぱいに使う。キャラ（LUNA）とフリップ「余り食材ガチャ」を今より大きくして、画面の真ん中に置く。スポットライトはそのキャラに1本、上から当てる。光る楕円の床もキャラに合わせて大きくする。
3. 「合格者待機室」の枠は左上に残し、テーマの帯のすぐ下に小さく重ねる。数字は「1 / 3」に直す（崩れた文字にしない）。
4. 見出しの横の「5 AI」のバッジを消す。
5. ゴールデンブザーと「賛成 2 / 4」、「これまでの挑戦者」の列、ヘッダー、テーマの帯、一番下の審査員のバーは、そのまま残す。
```
